# 核心页面与状态 · 组合方案

日期：2026-11-01。R4 已确认布局与字号；以下为第 5 轮页面细化；R9 已确认作为 M1 / M2 实现基线，细节继续完善，不是功能验收。入口：[可点击核心页面](review.html)。

## 已确认的布局与阅读基线

日常采用 A：对话左对齐、阅读宽度最多 780 px、工具步骤内联折叠。用户打开修改审查时采用 B：对话过程归组，右侧展示更宽的文件 / Diff / 审查区。关闭审查恢复日常布局，保留草稿、阅读位置和工具展开；不会切换会话、目录或任务状态。文件面板和终端按需打开，不触发审查布局。

侧栏 248 px；审查宽度在 1600 px 及以上为 640 px，1201–1599 px 为 540 px，1200 px 及以下为可关闭抽屉。窄窗优先保留输入、停止、审批决定及面板关闭入口。抽屉是暂时查看，关闭后回到原对话。正式可调宽度 / 布局恢复仍在 UX-01 / M4 验收。

界面正文 14 px、消息 15 px、辅助文字 12 px；正文行高 1.6，消息 1.8。Windows 系统字体，代码用 Cascadia Code / Consolas。该字号基线由用户明确确认；后续可配置字号与缩放，但不把当前稿件当作系统缩放 / 辅助技术完整验收。主题跟随系统、明暗同等设计。

评审栏的“组合 / A / B”和状态选择器仅用于审稿，不进入产品。组合为新默认，A / B 保留作参考；真实用户只操作“变更”的开关，不需要理解设计方向。

## 状态、反馈与恢复

| 样本 | 可见状态与主动作 | 约束 |
| --- | --- | --- |
| new | 新任务输入，发送 | 未发送不创建持久会话 |
| creating | 正在保存会话，发送禁用 | 保留正文，重复 Enter / 点击不能重复创建 |
| create-failed | 保存失败，重试创建 | 没有侧栏空项，不丢草稿；使用同一创建请求 |
| running | 正在执行，停止 / 引导 / 追加 | 工具准备与实际执行分开；不伪造思考 |
| queued | 等待执行资源，取消排队 | 尚未启动该模型任务，不显示为执行中 |
| approval | 等待决定，允许一次 / 拒绝 / 取消 | 无倒计时；看旧消息时不强拉阅读位置；初次进入定位到审批 |
| approval-invalid | 旧请求失效，重新检查 | 旧的允许按钮禁用，不能沿用旧参数授权 |
| settling | 回复结束，正在检查变更 | 不能仅凭模型结束事件显示本轮完成，也不提前放行下一轮 |
| stopping | 正在停止，等待执行系统确认 | 停止按钮禁用，不能把点击立即当作已中断 |
| stopped | 已停止，检查改动 / 继续 | 残留队列暂停，恢复须明确决定 |
| retrying | 正在等待重试，取消重试 | 展示原因 / 尝试次数；本稿不自动发起请求 |
| compacting | 正在压缩上下文，查看原记录 | 原历史保留，不展示未完成的规模；失败仍可恢复 |
| error | 请求失败与错误码，手动重试 | 记录重试范围，工具结果不确定不重放副作用 |
| offline | 连接中断，重连 | 旧状态仅供查看；发送 / 审批决定不可用，断线不等于任务停止 |
| reconnecting | 正在同步状态 | 同步完再决定下一步；不自动重放命令 |
| review | 本轮完成，逐文件接受 / 回滚 | 运行结果、审查进度和适用性分别显示；接受不提交 |
| conflict | 文件已有外部修改，查看差异 / 保留现场 | 禁用自动回滚，不提供默认覆盖；其他文件独立处理 |
| snapshot-failed | 基线快照失败，重试 / 取消 | 继续不可回滚必须另行显式确认，不默认继续 |

状态样本由评审栏手动选择。创建、停止、重连的完成也用明确的“推进样本”控件演示，不以假定的短定时器冒充真实服务确认。实际功能须由服务事件、持久化与 SDK / 文件证据验收。

## 组件与交互约定

- 输入：空白禁发；中文组合态不发送；Enter 发送 / Shift+Enter 换行；每会话及新会话草稿独立。创建中锁定提交，失败可编辑原草稿。
- 重命名：侧栏与标题菜单共用官方 Dialog / Field / Input，预填并选中现名；Unicode 码点 1–80，Enter 保存、Escape 取消，IME 组合期间两键不触发保存或关框。保存失败保留编辑，结果未知明确待核对；版本冲突展示最新标题，明确采用最新版本后仍需再次保存。后台同步不抢焦点、覆盖编辑或替换当前会话。
- 基础搜索：Electron 侧栏或 Ctrl+K 打开官方 Dialog，初始焦点在输入；中文标题 / 用户 / 助手正文按字面匹配。全部 / 指定 / 无项目、状态、本地日期起止、归档范围统一 200ms 防抖；每页 20 项、最近活动降序，显示路径 / 短 ID 区分同名项目。脱敏片段不超过 180 个码点（另可有省略号），正文命中进入原消息所在历史页并高亮。↑↓ 选择、Enter 打开、Escape 取消并返回焦点；IME 组合期间不触发这些动作。失败保留条件、明确重试，无结果可清除。搜索不发任务、不改变 cwd，迟到结果不覆盖新条件；760px 弹窗在原生最小 800px 窗口可滚动，明暗等同设计。
- 过程：准备 / 待审批使用时钟和文字；实际执行使用阶段描述；完成使用成功标记。状态不能只依靠颜色。内联步骤与轮次归组共用展开记录。
- 审查：宽面板有明确关闭按钮，当前文件与轮次可辨。接受 / 回滚按文件独立计数。历史 Diff 不被当前版本静默替换。混合或未知来源不提供盲目整轮回滚。
- 反馈：局部错误靠近操作；新消息 / 审批通知不抢焦点；回看有返回最新入口；操作后焦点返回有效入口。原型只模拟部分阅读现场，不等于长历史 / 虚拟列表已验收。
- 终端：打开不自动附加；显式选择输出后显示可移除上下文引用。正式 PTY 和进程管理仍属 EXEC。
- 设置：继承来源、影响范围、生效时机与实际支持能力可见。默认仅经验证的受限读取自动执行，写文件与命令先审批；任意 Shell 命令不因声称只读而放行。可显式授予有限会话权限，高危操作始终单次确认。设置展示默认规则与当前会话授权入口，不提供未经界定的“一键全部放行”。
- 资源信任：侧栏设置区进入，配对后检查明确目录，逐项显示来源、影响、指纹、预览与当前能力，再确认相应版本。按用户确认跨重启保存，来源或内容变化后重新确认；撤销从下一轮生效，当前任务和历史保留。当前只加载已确认文本，扩展 / 脚本仍禁用。失败保留旧信息并禁用决定，旧预览不批准新内容，取消恢复原焦点；实际页面见 `?trust`，验收边界见[实施方案](../architecture/implementation-plan.md#sec-07-已交付边界)。
- 工作区：Electron 从侧栏或 Ctrl+O 进入 `?workspaces`；选择器的取消保留当前选择，打开 / 切换显示校验状态，成功展示实际目录与身份并定位标题，失败聚焦路径并给出恢复操作。当前目录失效显示“需要重新校验”，连接失败不假称已停止后台任务；迟到结果不替换较新选择。目录打开不创建会话，也不自动确认资源；可显式进入当前目录的信任检查。本窗口列表与持久最近列表分开，网页独立操作暂缓。
- 最近工作区：成功显式打开 / 切换优先，同毫秒顺延；重命名、刷新、校验和重新定位不改变排序。展示最近 100 项及总数，记录不表示目录当前可用，打开时重新检查；失效项保留名称 / 路径、诊断与恢复入口。菜单提供重命名、恢复目录名、重新定位和从最近移除。重命名预填全选，去首尾空白后 1–80 Unicode 码点，Enter 保存 / Escape 取消，IME 组合不保存或关框；保存失败 / 冲突保留输入，核对最新版本后另行保存。移除确认明确只隐藏记录，目录、会话、自定义名、当前窗口和后台任务保留。重新定位预填旧路径，原生选择器只填值，明确保存时只接受移动后的同一物理目录；不隐式切换当前视图或既有会话 cwd。窄窗当前详情和最近列表按纵向滚动，内容不重叠。
- 模型发现：MODEL-01 在 Electron 侧栏设置区及原生“工作台”菜单进入 `?models`，显示来源目录、auth / models / settings 文件状态、SDK 版本、提供商 / 模型来源与能力、pi 默认模型的匹配结果。本地已配置与未联网验证并列，真实传输关闭；过期 / 缺失 / 命令禁用、未知 API、无效配置和离线无模型给出原因与 pi 配置指引，其他产品账号不推断为 pi 权益。默认仅显示已有配置，搜索与分批展开不访问提供商；刷新失败保留并标明旧数据失效，离开后的迟到响应不替换当前页面。未连接目录时引导显式设置 PIW_PI_AGENT_DIR 并重启，不改写或自动改选；网页独立功能和工作台配置编辑仍暂缓。
- 窗口：默认 × 收到托盘，已有任务及待审批继续；重新打开还原查看现场。菜单退出应用先保存记录、取消审批 / 排队、停止受管 Agent / 命令 / 终端与服务；未确认停止不能显示“已退出”。独立启动的服务须显式退出，不误停无关 CLI。浏览器关闭只断开观察，开机自启默认关闭。重启不恢复旧授权、不自动执行队列。原型提供行为说明，不操作真实窗口或进程。
- 用量：正式产品显示实际请求 / token 与费用未知状态；开发验收额度仅在评审说明和开发记录中追踪，不混成普通会话的产品用量限制。

## Electron 控制栏与统一设置 · 2026-11-02

按用户提供的 Codex Windows 截图调整实际应用，沿用中性灰、14 / 15 / 12 px 与 A / B 对话布局。顶部为 40 px 控制栏，后退 / 前进与文件 / 编辑 / 视图 / 帮助连接既有应用命令；采用 Electron Window Controls Overlay 保留 Windows 原生最小化 / 最大化 / 关闭和窗口交互。标题栏空白可拖动，按钮及菜单区域排除拖动；× 到托盘和显式退出语义不变。

桌面主体增加 48 px 导航轨道与圆角内嵌面板。设置通过侧栏“设置”、导航轨道或文件菜单进入 `?settings=appearance`；左侧 240 px 分类（较窄窗口 212 px）带本地搜索，右侧正文最多 840 px、内容独立滚动。小于 600 px 时分类改为横向滚动，当前分类保持可达。设置集中外观、模型与提供商（桌面）、凭证与隐私、客户端、资源信任和资源状态；原有查询入口继续兼容，敏感页仍须 SEC-08 配对。

外观提供跟随系统 / 浅色 / 深色，只有主题偏好保存在本机浏览器存储，受限时退回当前窗口；现有页面不再各自覆盖主题。Electron 同步窗口底色与原生按钮颜色，系统主题信号实时生效。字号与密度仅说明当前基线，完整调整功能仍待 UX-03。导航采用同文档切换，工作台在设置期间保留挂载，草稿、阅读位置与已展开审查不因返回而重建；不会创建会话或取消后台任务。当前开发样本及来源标记保留在工作台底部。

可点击 [PRD](../product/prd.html) 的模板与交互也同步顶部栏、导航轨道、全页设置、分类搜索与窄窗横向导航。工作台 DOM 在设置期间保留，原有五类完整功能设计继续可达；模型演示区分别标明来源、本地配置和未联网验证。窗口按钮仅为示意；原型、规格和对照视图继续区分设计与实际进度。

这次关联 UX-03 / UX-05 的部分实现，不验收完整布局恢复、多窗口、深链接、字号 / 密度配置及真实业务生命周期；不提高已验收功能数。离线门禁、实际 Windows 操作与限制在 [实施方案](../architecture/implementation-plan.md#electron-控制栏与统一设置)记录。

## SESSION-01 桌面首次发送 · 2026-11-03

Electron 默认进入实际会话工作台；浏览器首页和桌面 `?samples` 保留原离线样本。新会话沿用中性灰控制栏、248 px 侧栏及 780 px 输入阅读宽度，欢迎区居中；无项目与独立目录在标题和输入区均可核对。项目与模型有可访问标签，目录详情可选原生文件夹或输入完整路径，先由 daemon 校验。已保存会话分别展示项目归属和实际 cwd，已绑定配置不可在续发时静默改变。

首发未保存时显示“正在保存任务”，原子保存后侧栏出现本地脱敏标题。落库前失败保留草稿；落库后已知失败在原消息提供明确重试；连接不确定时锁住原请求正文 / 配置，提供“核对原提交”和“使用原请求重试保存”，不另建会话或自动重发模型任务。原生中断显示“已中断 · 未自动重发”，可另行输入新任务。新会话与各已有会话分开保存草稿，设置返回原会话，迟到回执只更新所属会话。Enter / Shift+Enter 与组合态输入分别处理。

模型选择明确区分“离线验收模型 · pi SDK 本地夹具”和已有提供商；后者标注本地配置状态 / 未联网验证，真实传输关闭时禁发，选择仍保留，目录中消失时显示不可用而不自动回退。已创建会话的消息区标明真实 SDK + 本地 HTTP 固定样本、工具与扩展关闭；普通样本与该实际链路不能混算验收。仅开发环境启用夹具，独立网页发送暂缓。完整阅读位置 / 工具展开 / 三视图缓存及旧 pi 历史发现已由 SESSION-02 验收，见下文。

## SESSION-02 恢复与旧历史 · 2026-11-03

Electron 按会话还原草稿、首个可见消息与像素偏移、工具展开、历史页及所选只读变更引用；MRU 最多 3 视图含新草稿。隐藏视图不因零尺寸覆盖书签，淘汰只断开自身观察，后台任务继续；侧栏状态与长标题分列，标题省略不遮“运行中 / 待审批 / 待处理”。后台结果不抢焦点或换面板，迟到结果只更新有效所属对象。重连 / 刷新同步 daemon 权威状态，不重发任务；存储失败提示当前仅内存可用，不承诺应用重启或跨窗口恢复。

侧栏“旧 pi 历史 · 只读”进入 `?legacy`，左侧外部来源，右侧消息 / 来源路径 / 原 cwd / 时间 / 版本。提供刷新、更早消息及按需全文；未指定显式来源显示空态，CLI 同写 / 替换要求刷新，半行与损坏显示原因，续聊禁用。真实 Electron 明暗 / 1080p / 800px、键盘及 Windows 原生操作见[逐项验收](../validation/session-02-evidence/acceptance.md)。生产工具审批、文件 / Diff 执行和完整布局恢复仍按对应条目验收。

## 状态提示、错误与工具卡的细化

以下定义展示与恢复行为，不改变已确认主布局。OBS-02 的实际 Electron 实现及验收来源见对应记录，原型不构成功能证据。

- 当前会话运行阶段在输入区上方设一个主要呈现位置；连接健康、局部操作错误和历史时间线各有职责，不能把同一运行错误重复弹成横幅、气泡和 toast。按操作 / 事件身份关联和去重，不只按错误文案相等判断。
- 准备工具参数、等待审批、实际执行、等待模型、重试、压缩和变更收尾分别说明。没有模型思考信息时使用“等待模型响应”，不伪造思考或完成进度；收到终态之前计时到点也不代表完成。
- 重试只有在权威事件提供等待期限时才显示倒计时；期限未知显示“等待重试”。到点改为“等待重试结果”等待事件，不由 UI 自发请求。终态提示可消隐，消隐不改变权威结果或清除待办；审批无倒计时，中止仍等待系统确认。
- 同一错误经推送事件和请求失败两条路径返回时仅保留一个主要反馈，可展开脱敏详情。较早的成功提示不能在新操作失败后继续冒充本次结果；不同操作的错误不能被误合并。
- OBS-02 当前阶段固定在输入区上方，按 session／request／turn 身份选择；旧操作保留历史状态。需同步提交、运行观察和持久队列后才能显示完成。工具未决、重试、压缩、队列衔接或 held／unknown 输入均保留未处理文字，不显示消隐按钮。
- 停止分为“正在请求停止”“停止请求已确认 · 等待停止结果”和“停止结果未知”。HTTP 成功仅确认请求；实际 SDK settled 或持久结果与运行时一致后才显示停止。失败保留任务与停止入口，离开视图不停止后台；同操作终态消隐只影响本窗口显示，不写历史、队列、未读或权限。
- 错误详情复用 TraceCollapsible，默认展开，可用键盘收起；状态区最多 26vh、必要时收缩并内部滚动，输入区设高度上限，消息阅读区至少保留 120px。明暗和 800px 窄窗共用布局；工具／审批／压缩／重试合成观察与实际 SDK 本地 HTTP 阶段分开验收。

## OBS-04 阅读现场与新消息

真实Electron对话回看时禁用自动跟随，新增会话行不设置强制定位锚点；新内容按用户／助手消息身份去重，多次流式delta只计同一条消息。窗口只保存有界消息指纹，不保存正文；首次发现的历史不叫新消息，daemon会话未读仍由结果版本与阅读回执独立裁定。

底部浮动“n条新消息 · 返回最新”只在下方仍有内容时可操作，计数采用完整语义的polite／atomic提示；后台变化不抢焦点。用户点击或键盘激活才跳到末尾并聚焦消息区、恢复跟随。历史入口明确写“返回本页末尾”，另有“返回较新一页”和“刷新最新历史”，不把当前页末尾混同于最新历史页。

阅读书签保存消息ID与像素偏移，原始scrollTop仅作后备；每一历史分页保存独立书签和有界返回栈，跨3视图淘汰／重新打开和本窗口renderer刷新恢复。显式展开／格式切换按当前消息锚点保持现场，异步Markdown和全文到达后继续校准，用户滚动即接管。明暗、1920×1080和800px窄窗使用同一入口。实现与实际证据见[OBS-04验收](../validation/obs-04-evidence/acceptance.md)。

显式收起长文时，按缩短后的正文高度限制保留偏移，保证预览和展开按钮仍可见，不产生空白。窗口阅读书签不承诺完整应用重启或跨窗口恢复；原生输入／截图与自动流程、合成审批／分页样本的来源均在 OBS-04 验收记录区分。

## OBS-03 工具时间线

Electron 受管对话、只读观察及本页历史复用官方 Trace／TraceCollapsible。每次调用有文字状态和独立按钮，Enter／Space 展开；展开后显示调用 ID、父调用、实际层级、执行目录、已知耗时／退出码、最终参数快照和结果。未提供的指标明确“未知”，未确认工具终态为“结果未知 · 已中断”。参数／父子／cwd／来源冲突保留原关联并显示诊断，乱序终态不被迟到 start 覆盖；缺父和循环保留可读记录，不推定并发时间。

文件、命令、变更摘要只依据已验证结构，读取范围标为请求范围；MCP 仅依据显式服务／工具元数据。参数／结果／Diff 使用安全纯文本，16k 预览可展开完整已捕获脱敏输出；上游截断明确说明，超限解析或未知结构回退原文。Diff 显示“仅观察／尚未关联可回滚账本”，没有回滚动作。合成样本逐卡标“合成观察 · 未执行”，生产工具／扩展继续关闭。

展开书签按会话中的 turn＋call 隔离，最多 3 视图和 renderer 刷新保留，不承诺完整应用重启书签。展开／收起沿用阅读锚点；ResizeObserver 后下一帧恢复，卸载清理。缩进视觉最多 4 层、实际层级保留文本，明暗语义 tokens、1920×1080 与 800px 窄窗共用入口。OBS-03 已补齐原生验收并 verified；[证据与边界](../validation/obs-03-evidence/acceptance.md)分开记录自动与原生来源。

返回最新先提交跟随意图，再由官方 MessageScroller 跳转；迟到正文布局产生的自动滚动不误记为用户回看。滚轮、触摸、滚动键与滚动条手势仍可中断跟随，消息区 Home 使用同一组件的即时滚动接口，避免浏览器键盘动画和迟到布局竞争；禁用浏览器独立锚定，显式展开保持所属消息锚点。


### SEC-10 目录与命令边界

真实会话输入区保留已保存模型，旁边的“模型与思考设置”使用现有Dialog／Field／Button。固定版本编辑，失败保留选项；并发更新须明确采用最新版本后再保存。按安装SDK实际能力禁用不支持级别；切模型先回off后显式选择。当前附件未开放，真实提供商传输关闭，离线模型与思考夹具明确标源。空闲保存立即成为会话配置，运行中显示请求配置与原配置，下一次SDK模型请求（含工具连续请求）确认后消除待生效。变更不停止任务、不改变cwd／权限、不发额外模型请求。


## MODEL-05 上下文与用量

会话标题区提供“上下文与用量”只读对话框；会话部分和与未知次数、最近请求的上下文参考、配置窗口、时间与来源置前，下面按轮次和消息展开SDK记录。缺失、默认0、损坏与竞争明确未知／未同步；价格没有有效来源和时间时不估算。关闭归还触发焦点，后台查询不抢焦点、不发送模型请求，明暗窄窗内部滚动。

## WS-04 目录占用与来源

Electron 会话工作区环境区显示目录空闲、本轮占用、其他会话占用、等待位置或退出待确认。展开可核对完整占用会话与轮次，等待原因明确为同一物理目录或父子目录重叠；所属会话的停止按钮取消等待，切换页面继续后台任务。目录等待不消耗模型／内核名额，独立目录可以继续执行。

文件元数据观察到变化后保留“来源不确定”提示及有界路径列表；没有变化不代表没有外部编辑。观察失败显示未同步，不把旧占用状态当作当前空闲。来源观察不是恢复快照，不能据此自动回滚。详情在原工作区区域内部滚动，保持输入和停止入口可达；明暗和窄窗使用同一语义主题与官方折叠组件。


## CHANGE-01 轮次文件版本

Electron 会话的工作区环境区使用官方 Badge／Collapsible／Alert／Button 组合，默认收起，显示基线与收尾状态。展开列出所属轮次、执行目录、不可变版本引用、文件／字节数、排除范围及失败诊断，最多每页 20 轮、当前 100 轮。失败可重新同步，不改变任务；目标卸载与迟到查询不恢复旧权限。基线失败时写入继续停在最终参数审批，必须单次明确接受不可回滚执行；文件版本保存不代表整轮可回滚。CHANGE-01 本身只显示版本与不确定来源，其明暗窄窗及原生验收见[最终记录](../validation/change-01-evidence/acceptance.md)。


## CHANGE-02／03 来源与历史 Diff

版本区域按所选轮次展开来源，显示文件路径、工具调用、确认区段及未解释区段。“工具观察一致”明确是观察证据；“混合来源／来源未知”不可当作 agent 独占修改。命令与外部副作用有单独提示。

“审查本轮文件差异”打开只读历史面板：宽屏与会话并排，1200px 以下使用现有可关闭 Dialog。文件列表显示新增／修改／删除／唯一字节一致重命名、二进制及真实行数，选中文件才读取正文。所属轮次和基线／收尾引用可核对；后来的当前文件修改不替换历史。无文件变更与版本不可用分开显示。

Diff 使用安全纯文本和统一脱敏，不解释 HTML、Markdown、链接或命令；二进制、非 UTF-8、大内容和脱敏后行结构不一致均明确说明。面板内部滚动、键盘可达，关闭归还触发焦点；迟到回执绑定 session／turn／file，切换或关闭不停止任务。明暗主题沿用语义 tokens。CHANGE-02／03 初版只有只读审查；后续接受和回滚入口见下节，各交付时点的证据分别保留。

## CHANGE-05／07／09／04 回滚与处理终态

所选轮次和所选文件都有明确预检入口。普通确认只允许全批无冲突，mixed／unknown 或当前不等于收尾时显示逐路径现况与目标，须在独立确认页明确覆盖。无默认覆盖、无倒计时，取消不写；失去回执按操作ID核对，不自动重试。历史Diff始终保留，当前条件展示所需版本与后轮依赖，最新回滚后重新核对。

接受仅记录保留决定；运行结果、已处理x/y和当前适用性分开。接受与成功回滚按文件ID并集计数，后续修改不擦除决定；失败／冲突／补偿不算处理完成。持久回滚记录可查询目标、前后引用、来源和结果，重启只读恢复；消息历史保留。窄窗沿用可关闭Dialog及内部滚动，后台任务和迟到回执按所属对象隔离。实际明暗／802px及原生来源见[验收记录](../validation/change-04-05-07-09-evidence/acceptance.md)。

## CHANGE-08 回滚范围与容量提示

最终参数审批和所选历史轮次详情共用同一范围组件，展示可回滚／部分可回滚／不可回滚、写入前或收尾观察依据、排除原因及5 MiB／32 MiB／2048项／8层限制。普通二进制文件字节与Diff能力分开；命令目录外文件、网络和进程副作用始终明确不受保护。范围不是来源或授权，原有单次不可回滚确认、混合／未知来源单独覆盖确认保留。

Git对象磁盘估算显示已用／上限、80%预警、容量满或未知及“保留所有已发布版本／自动清理关闭”；未知不显示零。必要引用失效说明基线／收尾对象无法验证，禁用预检与确认，取消仍可用；读取失败／同步中不使用旧许可。重新核对仅刷新，迟到绑定session／turn，视图操作不停止后台。明暗802×961、正常退出及同profile重启与来源限制见[验收记录](../validation/change-08-evidence/acceptance.md)。

## GIT-01 当前目录状态

会话／已校验草稿目录的“查看仓库状态”按需展开；显式刷新、收起和切换取消展示请求，不停止任务。状态列表区分 index／worktree／untracked、轮前内容一致、工具观察一致及来源不确定，说明不证明作者或独占。结果限当前 cwd 子树，仓库根仅作说明；失败隐藏旧列表，非 Git、过滤器／索引故障及不完整状态明确提示。窄窗采用已有可滚动环境区，不切换修改审查布局；不增加 Git 写入口。已验收来源见[记录](../validation/git-01-evidence/acceptance.md)。

## FILE-01 文件与快速定位

当前会话或已校验草稿目录的“浏览与查找文件”按需打开只读对话框，不切换修改审查布局。显示授权根、仓库根仅信息及附加根未开放；目录每页100项，可显式进入忽略目录。文件名／相对路径200ms防抖，IME期间暂停查询，关闭或切换仅取消观察，不停止SDK。位置核对、分页变化、权限与链接错误保持明确，根目录刷新恢复；不读取文件正文或自动加入上下文。范围及实际来源见[验收记录](../validation/file-01-evidence/acceptance.md)。
