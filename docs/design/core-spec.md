# 核心页面与状态 · 组合方案

日期：2026-11-01。R4 已确认布局与字号；以下为第 5 轮页面细化；R9 已确认作为 M1 / M2 实现基线，细节继续完善，不是功能验收。入口：[可点击核心页面](review.html)。

## 已确认的布局与阅读基线

日常采用 A：对话左对齐、阅读宽度最多 780 px、工具步骤内联折叠。用户打开修改审查时采用 B：对话过程归组，右侧展示更宽的文件 / Diff / 审查区。关闭审查恢复日常布局，保留草稿、阅读位置和工具展开；不会切换会话、目录或任务状态。文件面板和终端按需打开，不触发审查布局。

侧栏 248 px；审查宽度在 1600 px 及以上为 640 px，1201–1599 px 为 540 px，1200 px 及以下为可关闭抽屉。窄窗优先保留输入、停止、审批决定及面板关闭入口。抽屉是暂时查看，关闭后回到原对话。正式可调宽度 / 布局恢复仍在 UX-01 / M4 验收。

界面正文 14 px、消息 15 px、辅助文字 12 px；正文行高 1.6，消息 1.8。Windows 系统字体，代码用 Cascadia Code / Consolas。该字号基线由用户明确确认；后续可配置字号与缩放，但不把当前稿件当作系统缩放 / 辅助技术完整验收。主题跟随系统、明暗同等设计。

评审栏的“组合 / A / B”和状态选择器仅用于审稿，不进入产品。组合为新默认，A / B 保留作参考；真实用户只操作“变更”的开关，不需要理解设计方向。

## 状态、反馈与恢复

| 样本 | 可见状态与主动作 | 约束 |
| --- | --- | --- |
| new | 新任务输入，发送 | 未发送不创建持久会话 |
| creating | 正在保存会话，发送禁用 | 保留正文，重复 Enter / 点击不能重复创建 |
| create-failed | 保存失败，重试创建 | 没有侧栏空项，不丢草稿；使用同一创建请求 |
| running | 正在执行，停止 / 引导 / 追加 | 工具准备与实际执行分开；不伪造思考 |
| queued | 等待执行资源，取消排队 | 尚未启动该模型任务，不显示为执行中 |
| approval | 等待决定，允许一次 / 拒绝 / 取消 | 无倒计时；看旧消息时不强拉阅读位置；初次进入定位到审批 |
| approval-invalid | 旧请求失效，重新检查 | 旧的允许按钮禁用，不能沿用旧参数授权 |
| settling | 回复结束，正在检查变更 | 不能仅凭模型结束事件显示本轮完成，也不提前放行下一轮 |
| stopping | 正在停止，等待执行系统确认 | 停止按钮禁用，不能把点击立即当作已中断 |
| stopped | 已停止，检查改动 / 继续 | 残留队列暂停，恢复须明确决定 |
| retrying | 正在等待重试，取消重试 | 展示原因 / 尝试次数；本稿不自动发起请求 |
| compacting | 正在压缩上下文，查看原记录 | 原历史保留，不展示未完成的规模；失败仍可恢复 |
| error | 请求失败与错误码，手动重试 | 记录重试范围，工具结果不确定不重放副作用 |
| offline | 连接中断，重连 | 旧状态仅供查看；发送 / 审批决定不可用，断线不等于任务停止 |
| reconnecting | 正在同步状态 | 同步完再决定下一步；不自动重放命令 |
| review | 本轮完成，逐文件接受 / 回滚 | 运行结果、审查进度和适用性分别显示；接受不提交 |
| conflict | 文件已有外部修改，查看差异 / 保留现场 | 禁用自动回滚，不提供默认覆盖；其他文件独立处理 |
| snapshot-failed | 基线快照失败，重试 / 取消 | 继续不可回滚必须另行显式确认，不默认继续 |

状态样本由评审栏手动选择。创建、停止、重连的完成也用明确的“推进样本”控件演示，不以假定的短定时器冒充真实服务确认。实际功能须由服务事件、持久化与 SDK / 文件证据验收。

## 组件与交互约定

- 输入：空白禁发；中文组合态不发送；Enter 发送 / Shift+Enter 换行；每会话及新会话草稿独立。创建中锁定提交，失败可编辑原草稿。
- 过程：准备 / 待审批使用时钟和文字；实际执行使用阶段描述；完成使用成功标记。状态不能只依靠颜色。内联步骤与轮次归组共用展开记录。
- 审查：宽面板有明确关闭按钮，当前文件与轮次可辨。接受 / 回滚按文件独立计数。历史 Diff 不被当前版本静默替换。混合或未知来源不提供盲目整轮回滚。
- 反馈：局部错误靠近操作；新消息 / 审批通知不抢焦点；回看有返回最新入口；操作后焦点返回有效入口。原型只模拟部分阅读现场，不等于长历史 / 虚拟列表已验收。
- 终端：打开不自动附加；显式选择输出后显示可移除上下文引用。正式 PTY 和进程管理仍属 EXEC。
- 设置：继承来源、影响范围、生效时机与实际支持能力可见。默认仅经验证的受限读取自动执行，写文件与命令先审批；任意 Shell 命令不因声称只读而放行。可显式授予有限会话权限，高危操作始终单次确认。设置展示默认规则与当前会话授权入口，不提供未经界定的“一键全部放行”。
- 窗口：默认 × 收到托盘，已有任务及待审批继续；重新打开还原查看现场。菜单退出应用先保存记录、取消审批 / 排队、停止受管 Agent / 命令 / 终端与服务；未确认停止不能显示“已退出”。独立启动的服务须显式退出，不误停无关 CLI。浏览器关闭只断开观察，开机自启默认关闭。重启不恢复旧授权、不自动执行队列。原型提供行为说明，不操作真实窗口或进程。
- 用量：正式产品显示实际请求 / token 与费用未知状态；开发验收额度仅在评审说明和开发记录中追踪，不混成普通会话的产品用量限制。

## 状态提示、错误与工具卡的细化

以下细化后续开发的展示与恢复行为，不改变已确认主布局，不表示当前样例已支持这些行为。

- 当前会话运行阶段在输入区上方设一个主要呈现位置；连接健康、局部操作错误和历史时间线各有职责，不能把同一运行错误重复弹成横幅、气泡和 toast。按操作 / 事件身份关联和去重，不只按错误文案相等判断。
- 准备工具参数、等待审批、实际执行、等待模型、重试、压缩和变更收尾分别说明。没有模型思考信息时使用“等待模型响应”，不伪造思考或完成进度；收到终态之前计时到点也不代表完成。
- 重试只有在权威事件提供等待期限时才显示倒计时；期限未知显示“等待重试”。到点改为“等待重试结果”等待事件，不由 UI 自发请求。终态提示可消隐，消隐不改变权威结果或清除待办；审批无倒计时，中止仍等待系统确认。
- 同一错误经推送事件和请求失败两条路径返回时仅保留一个主要反馈，可展开脱敏详情。较早的成功提示不能在新操作失败后继续冒充本次结果；不同操作的错误不能被误合并。

| 工具结果 | 展示内容 | 不可解析 / 缺字段时 |
| --- | --- | --- |
| read / 文件 | 路径、可核对的行范围与截断说明 | 保留安全原文，不猜行号 |
| write / edit | 文件、实际变更摘要和可用 Diff | 回退脱敏参数 / 结果；工具卡不冒充 CHANGE 账本的回滚依据 |
| bash / powershell | 最终命令、执行目录、已知退出码 / 耗时、截断标识 | 缺失显示未知；不从输出文字推定成功 |
| grep / find / ls | 路径、可核对的命中位置、列表或上下文 | 复杂上下文按文本展示，不强行套结构 |
| MCP / 未知工具 | 稳定调用身份、服务 / 工具来源、参数和结果 | 无可验证结构时安全文本；嵌套 / 乱序返回仍绑定原调用 |

长输出按现有有界载荷策略展开 / 受控下载，展示解析不修改原始历史。高亮 / 可选图表按需加载并先展示原文；未知语言、未闭合围栏、超限和失败保留可读文本。支持图示时再补净化 / 隔离和故障样例，不要求 M1 提前引入渲染依赖。关联 OBS-01 / 02 / 03、MODEL-07。

## 会话面板、主题与桌面细节

- 文件 / Diff / 导出的在途结果始终回到发起时的所属会话 / 对象；切换回来按有效版本恢复，旧请求不覆盖新内容、不抢当前焦点。切换视图本身不取消真实运行，详见[会话设计](../product/session-design.md)。
- UX-01 完整布局接入时，自动收折使用不同的收起 / 展开阈值，避免边界抖动；手动收起保持到用户再次展开，空间不足时输入、停止与审批入口仍可达。阈值随已确认布局实测，不照搬参考像素值。
- UX-03 校验主题首帧和重启后的偏好，不先闪错主题再切换。Electron 可控的窗口底色 / 标题栏应与应用主题协调；尊重系统与原生标题栏能力，不为此默认采用新的自绘标题栏方案。
- UX-05 在 Electron 单独验证窗口按钮、托盘及焦点；若引入自绘标题栏，拖拽区域内的所有可点击控件须排除拖拽命中，不能只验证网页点击。× 到托盘和退出确认受管进程停止的规则保持不变。
- 设置页同时展示已保存版本、当前加载版本及生效方式；技能菜单与设置使用同源能力信息，发现但未加载的能力不能冒充可执行。重建内核不热替换在途工具。关联 EXT-01 / 07。

上述场景随各功能进入实际应用离线样例与浏览器 / Electron 检查，不把静态原型切换或安装组件计作验收；具体门禁见根 [AGENTS](../../AGENTS.md)。
