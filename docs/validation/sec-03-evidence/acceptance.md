# SEC-03 会话授权查看与撤销

已验收，新增十项中的第 3 项；SEC-01、SEC-02 已独立验收并提交，本项两条验收全部勾选。

会话授权由 daemon 的 SessionGrantService 独占，最多 64 条，仅内存持有真实匹配键。明确的普通调用审批才能授予，客户端不能提交范围字段或通配符；会话、工具、物理目录及全部祖先、目标路径、完整 canonical 参数与策略版本共同匹配。L3、子调用和未验证能力不能生成授权。展示统一脱敏，指纹匹配原文；不是目录信任、凭证、系统沙箱或其他工具权限。

当前尚无 CHANGE 可回滚基线，会话授权只复用已展示的工具权限范围，每次副作用仍须单独确认本次不可回滚风险。授权不会自动触发或重放调用，也不将一次不可回滚确认扩展为未来动作。单条及本会话全部撤销先同步移除权限，再写脱敏审计；审计失败仍撤销并显示警告。最终所有异步检查完成后再次检查授权，阻止撤销竞态。撤销不停止已执行动作，停止入口单独操作。服务重启或策略变化清空权限，历史仅审计不可执行。

Electron 复用既有 Dialog／AlertDialog、Alert、Trace、Button、Badge；Empty 从官方 CLI 的 base-nova 注册表获取源码，复用现有 cn／cva，无新运行依赖、锁或配置改变。Dialog 显示确切目录、目标、参数、指纹、来源和有效期；关闭返回焦点，断线禁用决定，失败保留核对内容，后台不抢草稿。没有新增设计系统，本机 UX 搜索未成功运行，布局依据已确认核心规格及组件规范。
