## 运行规则

- 只读当前登记物理 cwd，复用 FILE-01 四个真实 IO 槽、取消与退出 drain。句柄或链接中的路径只是定位输入；daemon 逐级核验后才读取，不新增根或修改文件／Git。
- 读取普通单链接文件，稳定 descriptor 前后及路径链复核；最多 256 KiB／10,000 行。严格 UTF-8（支持 BOM），二进制、其他编码、超限、失效／删除分别说明。统一全文脱敏；若脱敏改变行数则不展示会误导的代码行。
- 正文标为某次读取快照，显示真实路径、版本和核对时间；打开、恢复焦点、两秒可见轮询及加入输入前重新检查。检测变化或检查失败隐藏旧正文；必须显式刷新才读新版本，不承诺 OS 文件锁或零间隔监测。
- 每页最多 200 行，按行号定位、选择连续行。加入前重读匹配版本，最多 200 行／32 KiB；只追加到当前仍未变化且未锁定的所属草稿，不调用模型、不自动发送。取消／切换／迟到不得覆盖其他草稿。
- 工具最终 JSON path／offset、消息的明确本地 Markdown 路径链接及历史 Diff 的路径／新行号可打开当前文件；所有路径经同一 daemon 边界。历史 Diff 保留原账本内容和引用，当前阅读独立标注，不以当前文件替换历史。
- 没有编辑／保存、系统编辑器、附加根或新的自动上下文注入。真实提供商 0，pi 配置／canonical 预算／锁不改，OPS-08 继续跨阶段门。

- **初次定向 E2E 为 4/5：** 消息路径夹具超时，改为上述明确合成观察后 5/5。保留 [首轮日志](e2e-first-failed.log)和[页面错误现场](message-first-failure.md)。没有删去导航、越界或危险协议断言。
