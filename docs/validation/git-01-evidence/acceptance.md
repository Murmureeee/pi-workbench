## 运行规则

daemon 仅接受已配对 desktop 的注册 workspace/session 身份，会话使用原 cwd；不接受任意路径。复用物理目录复核，Git 只列当前执行目录子树；仓库根仅作环境说明。显式展开或刷新才查询，收起、切换和取消查询不停止 SDK 任务，失败不展示上次结果。

Git staged、unstaged、untracked、冲突及分支是当前观察；轮前字节与最终工具字节链分别列出。轮前内容一致不证明人类作者，工具观察一致不证明 agent 独占；外部混入、版本缺失、证据不连续及未核对项目明确来源不确定。不将原始字节与当前 index/HEAD 的差异当作历史暂存状态；换行规则可影响字节比较。不替换不可变历史 Diff。

每次最多四项检查，每命令 4 秒／2 MiB，最多展示 500 项、来源核对前 50 项，超限明确不完整。Git 环境、状态、过滤器属性前后复核，来源字节另复核；变化拒绝混合结果。此为有界时点观察，并非文件或分支锁。

子模块内部状态不递归扫描，存在 gitlink 时明确结果不完整，不把未扫描子模块称为干净。仓库过滤器生效、超时及损坏时保留诊断；当前安全读取范围之外的状态需要外部 Git 核对。

命令关闭 optional locks、fsmonitor、自动 GC/maintenance 和 untracked cache，不修改用户 HEAD/index/config/reflog。已配置的可执行过滤器在状态命令中置空；实际使用该过滤器的跟踪文件给出不可安全读取诊断，未生效的系统 LFS 配置不误拦截普通仓库。不执行 hooks、textconv 或网络。Git、索引、身份或权限异常均明确降级并可刷新。
