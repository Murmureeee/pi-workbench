## 实现与边界

- SDK 1.4.0 `message_end` 后才提取 `ThinkingContent`，不发布推测中的 delta；只取 `thinking` 文本。`redacted:true`、未知结构整条不可展示，签名与加密连续性载荷不进入 IPC／REST／WS／历史展示或下载。不伪造隐藏推理、不请求额外摘要。
- 思考与普通正文分离，普通完整内容及搜索不包含结构化思考。SDK 原生 JSONL 保留原文；检查点可保存公开观察；恢复读取原生历史，不重发模型。没有信息分别显示未提供／模型未声明支持／不可展示。
- 使用现有官方 TraceCollapsible 和 MessageBody；默认折叠，展开按当前会话与消息保存。上限 65536 字符，超限明确说明；复制和下载只含经统一脱敏的公开文本，操作不联网。
- 设置中的本窗口隐藏选项只保存布尔偏好，隐藏后不挂载正文且不提供复制下载；不删除历史或撤销已复制内容。隐私开关由实际 Electron 自动回归验证，原生验收不修改隐私设置。
- 诊断导出对完整 JSON 过滤被屏蔽的思考正文与签名；包含思考字段但损坏的记录拒绝导出，原件保留。旧 pi 历史仍只读，未新建续聊入口。
- 新增必需能力 `reasoning-observation-v1`；旧持久记录字段可缺失，协议缺能力仍阻止不兼容客户端。
