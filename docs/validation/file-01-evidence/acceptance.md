## 运行规则

- 仅已配对 Electron 通过工作区／会话身份请求 daemon；会话使用原 cwd，工作区沿用物理身份。仓库根仅说明，附加目录未开放。浏览不登记目录、不改变最近顺序、Git 元数据、授权、消息或 SDK 任务。
- 路径逐级 lstat／realpath；复用 SEC-10 私密与歧义路径规则。链接、硬链接、设备、私密目录和目录外目标不跟随。显示脱敏，客户端只提交宿主有界、五分钟过期的句柄，不把显示路径作为访问凭据。
- 目录异步按文件系统顺序每页最多 100 项；游标绑定物理目标、目录版本与偏移，单目录最多 5,000 项。变化拒绝混合分页，返回根目录刷新恢复。忽略／默认跳过／不可访问项单独标记；用户可以明确进入同根内的忽略目录。
- 快速查找是文件名／相对路径字面匹配，不读正文。最多遍历 5,000 项、12 层、100 结果、2 秒软限额；检查在有界 IO 之间进行。跳过忽略、依赖／输出目录、私密项、链接与不可访问项，Git 规则未知时不自动扩展。部分覆盖明确提示。
- 最多四项并行文件 IO，取消保持占用至底层 IO 结束。200ms 防抖、IME 期间停止展示查询；关闭／切换和迟到结果仅影响所属视图，不停止后台任务。
- 选择文件只重新核对当前位置与大小；文件内容、行号和输入引用留在 FILE-02 顺序验收。无编辑、保存、系统打开或授权扩大。
