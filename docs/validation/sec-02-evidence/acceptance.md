# SEC-02 执行前审批与失败关闭

已验收，新增批次第 2 / 10 项。依赖 SEC-01／CORE-05 已验收，两条验收全部勾选。

daemon ApprovalService 持有最多 64 个内存等待对象，不设倒计时。最终参数、工具、cwd、session／epoch／turn／call／parent、digest 和策略版本绑定同一单次决定；首个有效客户端决定同步消费，先保存决定再返回许可。关闭展示或短断线仅断开观察；取消、停止、IPC／内核失效、服务退出和策略失效唤醒并阻止旧决定，重启只保留 executable=false 的审计记录，不恢复 waiter 或内核。拒绝、取消或失效同时封闭本轮剩余待审批，失败保存也不得放行。

固定 write／edit 仅可申请实际 cwd 内、核验物理祖先和普通文件的变更；私密、链接、硬链接、设备、网络和越界路径继续拒绝，失败的 read 不改用 SDK IO。审批前后核对目录／目标身份；异步检查全部结束后再次检查任务和策略，变化时不执行。Shell 不按只读注解自动放行。CHANGE 的回滚账本尚未交付，允许仅经二次确认明确接受本次不可回滚执行；不生成会话授权，不承诺 OS 沙箱、外部副作用恢复或阻止同 OS 用户外部程序竞态。

Electron 复用 Alert／Badge／Trace／Field／Input／Button／AlertDialog，输入区上方显示实时待决定对象，侧栏和资源页显示待审批。最终参数统一脱敏、摘要指纹仍绑定原文；失败保留说明且不自动重新提交，断线禁用决定，后台不抢焦点。旧合成审批和只读观察仍不能执行。没有新增 primitive 或依赖，网页独立操作仍暂缓；协议新增 execution-approval-v1，旧客户端不得发变更。

服务测试使用真实 SQLite／SDK 子进程／私有 IPC／本地 HTTP；多端用两个分别配对的 desktop HTTP 身份争抢同一决定。Electron 自动回归操作真实桌面 main／preload／renderer，HTTP／WS 仅路由至隔离本地 daemon；模型内容为离线工具调用夹具，未合成工具执行或文件结果。旧工具拒绝用例使用仅测试注册的显式拒绝者，不在产品里自动批准或拒绝。

首次定向失败独立保留：新增夹具缺少第二个本地 SDK 回合的上限、旧测试把并行工具数组顺序当调用身份、两处新选择器未限定最近列表，以及失效文案缺少“未执行”。按真实调用 ID 与权威结果修正，文件零副作用、旧许可失效和脱敏断言保留。真实提供商请求 0；pi 配置、canonical 预算和锁文件未改，无安装包。
