## 运行规则

- 已配对 Electron、当前登记物理 cwd 内已有单链接普通文件。最多 256 KiB、10,000 行，只接受完整严格 UTF-8；支持有／无 BOM，统一 LF 或 CRLF，无换行文件新增行为 LF。拒绝混合换行、单独 CR、二进制、无效 Unicode、需要脱敏的正文或路径。原始末尾换行、BOM、空文件及其他字节不自动格式化或规范化；只将编辑控件的 LF 按原统一换行编码。
- daemon 所有权与四个编辑 IO 槽；保存和 SDK／回滚共用重叠物理目录互斥。保存期间以 Windows 原生独占文件句柄持有目标，并持有全部祖先的禁止删除／重命名句柄；锁内拒绝重解析点、多硬链接、身份／ACL／元数据／字节版本不匹配。无法证明边界或其他宿主拒绝保存。目标不新建、不删除、不更名，不扩大根。
- 外部改写及权限版本冲突保留编辑稿。只有产品内另一次“明确覆盖本次磁盘版本”允许覆盖刚检测的版本，绑定当前稿件哈希、文件版本和客户端，单次使用；再次变化仍冲突。删除或文件／目录身份替换直接拒绝，不靠覆盖确认扩权。明确覆盖是产品决定，开发授权不代替它。
- 成功保存写入并 flush；写入异常在原独占句柄内尝试恢复原字节。恢复失败明确磁盘可能部分写入、结果未知，保留稿件且不自动重试。进程或系统崩溃期间不承诺事务式文件替换；下次必须重验磁盘。取消发生在启动写入前则不写；写入启动后不杀 helper，实际结束前不释放目录互斥，迟到结果只更新所属稿件。
- 每窗口最多四份稿件，与文件和会话目标绑定，关闭阅读、切文件／会话和视图淘汰保留。当前窗口 sessionStorage 保留基线与文本，刷新恢复；暂存失败明确警告，只有内存保留。撤销最多 20 状态／每稿 1 MiB，刷新重置撤销栈。满额时要求先保存或单独确认丢弃其他稿件，不静默淘汰未保存稿。应用退出、应用重启或系统关机不保证恢复，正常离开遇未保存／未知结果须明确决定，取消回到现场；关闭到托盘保留。崩溃丢失风险不伪装已持久备份。
- 保存是用户／外部修改，daemon 脱敏追加审计记录请求和完成；保存原文、凭证不写审计。历史 Diff、基线／收尾版本、接受决定、工具观察和用户 Git 不改写；既有混合／未知来源仍不确定。文件编辑不启动或重发模型，真实提供商请求 0。
