# WS-07：工作区信任与不可用恢复

两项验收均通过，WS-07 verified。自动与原生证据分别归档，来源和边界见下文。

## 行为与边界

Electron 对话显示受限资源、目录失效原因和恢复入口。未信任文本不加载，扩展／设置脚本／安装动作保持禁用；信任指纹增加项目与来源目录的物理身份，原路径同内容的替换目录不能复用旧确认。旧记录保留，但旧版仅绑定路径与内容的指纹需要重新确认。

daemon 在资源准入前后做原有目录复核，并每秒采样排队／后台任务的原 cwd、物理身份和可读性。失效取消尚未发送的队列任务；已 dispatch 轮次中断，实际 SDK 进程退出后释放，不提供“已知失败”的直接重试。恢复／重连／重启均不自动重发。采样不是 OS 沙箱或瞬时挂载监测，后续真实工具仍需最终执行守卫。

恢复检查只检查身份／读写探针，不改最近排序、cwd、项目、信任或历史。重新定位仅同物理目录并使用 CAS，选择器不自动保存；已有会话保留原 cwd，需恢复原物理目录和登记路径后继续，也可明确在新位置新建会话。SESSION-13 的真实环境迁移未开放。
