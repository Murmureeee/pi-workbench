从描述任务，到可验证地交付

本轮重设计的原则

  • 任务为中心：对话承载意图与决定；文件、审查、终端围绕当前任务按需打开。
  • 渐进展示：新会话只显示输入所需信息，运行后出现过程，产生修改后出现审查。
  • 环境可确认：整理项目不迁移目录；切换查看不迁移执行；权限不简化为模糊的“自动”。
  • 完成有依据：运行结束、修改已审阅、测试通过和需求已验收是不同结论。
  • 恢复有路径：每个等待、失败、冲突、不可用状态都提供下一步。

面向单操作者和本机使用；账号、团队、远程主机、云端、浏览器操作及语音等保留在 M8 逐项评估。用户发起的 Git / PR 纳入 M6，多 Agent 和自动化纳入 M7。

对象关系

项目是组织容器；工作区是文件环境；会话持有可空 projectId 和独立 workspaceId；轮次持有工具、审批、变更与验证；终端归工作区；自动化关联环境与单次运行；子 Agent有父任务、独立身份和证据。授权不随归属移动或历史分叉复制。

完整用户旅程

每条旅程包含入口、主路径、异常与结果。按钮加载模拟场景；需求 ID 定位原始验收。原型未执行真实工具，工程实现仍需按阶段验证。

J01 首次启动与环境准备

入口：首次启动，或尚未配置可用模型 / 工作目录。

  1. 检查 pi、Git、Shell 与本地服务，按能力显示可用 / 缺失 / 待验证。
  2. 选择已配置模型，或前往提供商配置；密钥由宿主安全保存。
  3. 添加项目可跳过；桌面选择目录先核对实际路径、物理身份和读写能力，同目录别名复用。目录可打开与资源可信分开，未确认资源不自动加载或执行。
  4. 浏览器先完成本机配对，再接入同一服务。

异常与等待：缺依赖可重检；无模型保留草稿并指向配置；目录失效或权限不足时保留当前选择，恢复后重试；重新定位另行确认，不能悄悄改到另一个目录。切换查看不停止后台任务。

结果：用户进入可输入的新会话页；没有因此生成空会话。

J02 输入任务，首次发送创建会话

入口：全局新会话、项目旁的 +，或快捷键。

  1. 全局默认无项目，项目入口预选项目；输入区显示实际执行位置。
  2. 选择模型、思考级别、讨论 / 计划 / 执行模式；保存独立草稿。
  3. 首次有效发送以请求 ID 原子保存会话与首条消息，再启动任务。
  4. 默认本地脱敏摘要命名，不额外调用模型；模型润色显式启用，人工标题优先。

异常与等待：空输入不发送；输入法组合态不提交；重复请求去重；创建失败保留草稿，启动失败保留同一会话供重试。

结果：持久会话只有一个，侧栏立即可见，新会话居中布局转为对话布局。

J03 找回、命名与整理长期工作

入口：侧栏、标题菜单或搜索。

  1. 搜索标题和用户 / 助手正文，组合项目、无项目、归档、状态和时间筛选。
  2. 结果保留标题、项目、摘要；正文命中直接定位对应消息。
  3. 重命名预填旧值，1–80 字符，允许同名，Enter 保存、Escape 取消。
  4. 移动项目只改变组织归属；如需改执行目录，另行预检并确认。

异常与等待：无结果给出清除筛选入口；重命名冲突保留编辑；运行、队列、待审批或未审查修改存在时禁止迁移执行环境。

结果：标题、归属和实际目录各自明确；列表、搜索与其他客户端保持一致。

J04 准备上下文并先讨论 / 计划

入口：输入区模式、+、@ 文件或 / 命令。

  1. 引用显示路径、行范围、大小与来源；发送前可预览 / 移除。
  2. 讨论只解释；计划允许受控只读调查，并输出可编辑步骤和验收条件。
  3. 澄清以结构化问题卡提交，取消和超时均不算同意。
  4. 用户审阅计划后明确转为执行；权限变化与需要的审批单独展示。

异常与等待：不支持的附件、变化后的引用和未知命令保留草稿并显示处理方式；计划模式不偷偷写文件。

结果：任务说明、计划、上下文来源与可用工具范围可以回看。

J05 观察运行，纠偏与追加任务

入口：任务启动后，用户继续阅读或输入。

  1. 运行摘要显示思考、工具、重试、压缩、收尾；工具默认折叠，可展开参数与结果。
  2. 引导在可用模型边界进入当前轮，追加等 settled 和快照完成后开启下一轮。
  3. 两类队列各自 FIFO，可编辑 / 移除；用户回看历史时只提醒新消息。
  4. 停止可保留或清空队列，保留已产生结果与修改。

异常与等待：断线显示重连并从权威快照恢复；停止后的残留队列等待用户恢复，不能自动重发。

结果：运行状态与消息是否实际送达可核对，不把模型停顿或自述完成当验收。

J06 执行前审批与授权管理

入口：最终工具参数命中审批规则。

  1. 对话内展示待执行参数、目录、风险、影响和可回滚范围。
  2. 提供允许一次、本会话允许、拒绝；L3 只允许单次确认。
  3. 首个有效决定生效，参数变化使旧审批失效，多个请求按顺序处理。
  4. 在会话详情查看授权范围并撤销；收紧策略立即作用于后续调用。

异常与等待：本地审批无倒计时，断线 / 关闭展示不放行且可稍后处理；取消、运行时或参数失效关闭旧请求；已运行操作需单独停止，撤销不抹审计。

结果：调用结果和审批证据绑定最终参数，浏览器和桌面共享同一决定。

J07 审查本轮变更与安全回滚

入口：写入结束、失败或中止后，从变更摘要打开右面板。

  1. 显示轮次基线、来源、增删行数和排除范围，用户已有修改独立标注。
  2. 逐文件查看 Diff，接受只记录保留意见；回滚预览真实写入范围。
  3. 整轮回滚先校验对象与全部末态，任一预检冲突整批不写；运行期失败有条件补偿，无法补偿时保留现场并显示需要恢复。
  4. 审查进度、运行结果和当前适用性分别显示，混合接受 / 回滚也可全部处理。

异常与等待：基线失败暂停写入；来源不明、外部编辑、后续覆盖或快照缺失时禁用不可靠回滚，提供手动对比。

结果：保留当前代码和审查历史，回滚留下系统记录，不隐式提交 Git。

J08 查看文件、预览与继续提问

入口：文件路径、@ 引用、文件面板或产物链接。

产品决定与设计依据

优先顺序：backlog D01–D15 与产品规划 → 功能验收 → 本交互设计 → 架构草案。决定直接生成，防止长期保留矛盾。

D01 产品目标与范围

目标是基于 pi 的完整个人编码工作台，覆盖类似 Codex 的项目、会话、观察、控制、审查和交付体验。本地完整版覆盖 M0–M7；M8 为候选扩展，不计入本地完整版完成率。模型质量、订阅权益与专有云服务不由界面保证。

D02 现有文档的关系

全量范围、阶段和状态以 backlog JSON 与总规划为准；实施方案与用户确认记录确定技术路线：React / Electron、NestJS + Fastify 本地 Node 服务、Drizzle / SQLite 与 pi 原生 JSONL，pnpm 单仓库。PI-Desktop 作为规格 / 交互参考。项目结构设计明确应用与公共包边界；交互 PRD 提供界面方案，架构提供实现细节。冲突按 D01–D15 和最新确认回填。

D03 同目录修改互斥

同一物理目录最多一个 agent 写入轮次；受工作台管理的写入任务及回滚也需互斥。只读观察可并行。用户终端和外部编辑无法靠账本锁隔离，混入时标明来源不确定并限制整轮自动回滚。真实并行写入使用独立 Worktree。

D04 轮次与队列边界

产品轮次是宿主接纳的一条任务及其自动延续，不等于底层每个模型回合。引导进入当前轮次；追加由宿主等待当前轮次 settled 且快照完成后启动下一轮。引导与追加各自 FIFO，展示实际送达顺序。中止保留队列但不自动再次送达。

D05 审批等级与授权

新会话默认仅经验证的受限读取自动执行，写文件和命令先审批；任意 Shell 命令不因只读声明放行。可显式授予有范围的会话权限。所有匹配规则取最高风险，不按未排序规则首次命中。审批针对最终执行参数；后续扩展改写参数须重判。L3 始终单次确认。会话授权可列出并撤销单条或全部，撤销只影响后续调用，已执行动作需单独中止。

D06 审批策略与失效条件

“要求审批”开启表示收紧，关闭表示放宽；放宽须明确确认。收紧立即作用于后续调用并作废不再满足策略的授权。本地交互审批无倒计时，切换会话、关闭展示或短暂断线不裁决；取消、归档、服务退出、内核重建、参数或策略失效会终止旧请求，重启不恢复旧授权。无人值守未预授权动作拒绝，不复用无限等待策略。

D07 回滚承诺

仅对成功记录基线与末态的受支持文件提供回滚。基线失败时暂停 agent 写入；用户可对当前动作单次确认不可回滚执行。审批及结果注明排除文件、大文件、工作区外修改与命令外部副作用，不宣称任意命令都可逆。

D08 状态与完成

分别记录运行状态、审查进度与当前文件适用性。接受一文件、回滚另一文件可达到全部已处理。后续修改不抹除历史审查决定，也不一概表示旧改动已消失。模型结束或子任务自述完成均不等于功能已验收。

D09 历史分叉

默认只分叉消息历史，继续使用当前文件，不复制审批授权。界面和新会话中明确记录这一事实。历史文件恢复必须通过独立快照或 Worktree 操作，不随点击分叉隐式发生。

D10 服务与窗口生命周期

浏览器关闭只断开观察，服务继续。桌面 × 默认收到托盘，已有任务与待审批继续；开机自启默认关闭。菜单“退出应用”保存记录、取消待审批和排队、停止其受管服务、agent、命令与已接入终端，确认停止后才完成退出；失败列出未停止对象。不误停独立 serve 或其他 CLI，独立服务须显式退出。重启只恢复记录，不恢复旧授权或自动重放队列与副作用。

D11 浏览器与远程边界

M0–M7 默认仅回环访问，浏览器与桌面共享服务权威状态。网页配对会话暂定最长 7 天、闲置 24 小时失效，服务重启失效；关闭标签不要求每次重新配对。浏览器不持久缓存会话正文。局域网与跨主机执行移到 M8 独立评估。

D12 隐私、快照与审计保留

审计和快照分开管理，agent 不得修改审批证据。未审查且仍需回滚的快照不静默回收，容量不足先提示处理或停止受保护写入。清除审计、删除历史与回收快照必须展示各自影响。

D13 能力来源与兼容

原生会话、事件、队列、压缩和 fork 可复用 pi 已有接口；SDK 中 MCP 扩展需显式加载与绑定。多 Agent 使用扩展或宿主编排。第三方 TUI、自定义组件、沙箱和远程适配均须验证，不因 CLI 可用就宣称工作台已支持。

D14 进度与证据

需求范围、详细设计和实现状态分别记录。完成需对应验收全部通过、依赖已验收并有实现和验证证据；当前完成数从 features 的进度及既定统计口径计算，不从旧正文复制。技术方案、原型和参考产品源码不增加已验收数；后续实现仍逐项记录。

D15 首次发送建会话，归属与目录分开

进入新会话页只保存独立草稿，首次发送才创建持久会话。项目可选，无项目会话使用宿主管理的独立目录。默认按首条消息生成本地脱敏标题，模型润色默认关闭；命名不阻塞主任务、不覆盖人工改名。基础搜索、重命名和项目组织均在 M2。项目归属与执行目录及授权分开，整理归属不隐式切换环境；目录迁移需空闲、清理待办并预览确认。
