## 目标流程

用户点击“新会话”，在输入区描述任务，选择项目或“无项目”，直接发送。系统创建会话、开始响应并自动起名，用户可随时重命名，之后通过侧栏、搜索和项目找到它。

进入新会话页面不要求先填名称或先选目录，也不立刻生成空白会话记录。本文参考 Codex 的会话组织方式，具体默认值、标题策略和迁移规则是 Pi Workbench 的产品决定。

## 新会话页与首次发送

1. 侧栏提供全局“新会话”入口，每个项目内也有新建入口。全局入口默认“无项目”；项目入口预选该项目。项目选择器始终可见，不默默沿用其他会话的执行目录。
2. 页面包含任务输入区、可搜索的项目选择器、模型和思考级别、发送按钮。进入即聚焦输入区，不弹出必填命名对话框。已有会话的发送始终继续当前会话，只有进入新会话页才创建另一会话。
3. 未发送的内容作为独立草稿保存，至少恢复正文、已选项目、模型与显式执行目录；切换到已有会话不会把草稿发到那个会话。同项目入口重新打开原新草稿保留所选目录，切换项目归属才清除目录覆盖并使用目标默认值。M4 附件能力接入后同样保留其引用与上传状态。
4. 首次发送校验正文、模型与执行环境；纯空白内容不能提交。中文输入法选词中的 Enter 不发送，Enter / Shift+Enter 的行为与 INPUT-01 一致。
5. 服务先持久化稳定会话 ID、创建请求 ID、首条消息和待运行状态，再安排内核启动。保存成功后会话立即出现在侧栏，页面进入该会话；自动命名和模型响应独立进行。
6. 创建中显示明确反馈，防止重复提交。客户端重试同一请求使用同一幂等键；服务返回同一会话和首条消息，不重复创建或重复排入运行队列。
7. 落库前失败时保留完整草稿，不留下列表空项。落库后内核或模型失败时保留原会话与首条消息，在该会话显示错误和重试入口。响应丢失先查询创建结果，崩溃恢复不自动重放执行结果不确定的副作用。
8. 进入新会话页后未发送即离开，不产生永久“未命名会话”。跨端共享已经创建的会话；未发送草稿默认只在当前客户端保存。

## 自动生成会话名称

- 首条消息保存后，立即生成本地标题：折叠空白、取脱敏有效内容摘要，最多 40 个 Unicode 字符。默认长期使用此标题，不额外调用模型。M4 的仅附件输入分别使用“图片讨论”或“文件分析”作为回退。
- 模型润色默认关闭。用户显式启用后，才在后台用当前配置的提供商 / 模型生成一次简短标题；仅使用首条消息必要内容，不读文件、不调用工具、不写入主历史。用量单独归类到命名开销，不另要求配置提供商。
- 可选模型命名等待上限 10 秒；超时、离线、拒绝或空值保留本地标题，不阻止主任务。关闭后不再新建命名请求，迟到结果也应受有效请求与标题版本校验。
- 标题是纯文本，不渲染 HTML；去除控制字符，拒绝空标题，限制长度。隐藏凭证等敏感字段不写入标题、搜索预览或通知。
- 标题具有来源（本地摘要 / 模型 / 用户）与版本号。模型结果仅在对应请求仍有效且用户未改名时写入；迟到结果不得覆盖人工标题。后续消息不反复自动改名，用户可以显式选择“重新自动命名”。

“重新自动命名”区分重新生成本地摘要与显式模型润色，不把点击本地操作隐式转换为付费请求。跨端使用 compare-and-set 校验来源 / 版本 / 请求 ID，模型超时不影响人工改名。

## 切换、分页与后台现场

SESSION-02 已实现以下恢复边界，OBS-04 的完整观察能力仍独立验收。按会话保留草稿、消息锚点与偏移、展开工具和工作面板上下文。初始最多保留 3 个会话视图，卸载其他视图不停止后台 agent；重新打开先还原阅读锚点，再同步权威状态。历史初始最多 100 条 / 页，单条展示载荷 64 KiB；完整内容可展开读取，不得将展示片段写回原生历史或模型上下文。

后台消息、审批和产物只更新所属会话及其待办标识，不抢焦点或替换当前文件 / Diff。本地工具审批持续等待显式决定，无倒计时；关闭展示或短暂断线不裁决，取消和运行时失效会关闭旧请求。视图缓存与内核进程池独立。

当前 Electron 的 MRU 上限 3 个视图含新会话草稿；小型书签与草稿保存在本窗口 sessionStorage，支持刷新 / 淘汰恢复，不承诺整个应用重启或跨窗口草稿。正文、队列与执行状态只从 daemon / SDK 同步，重连不重复 prompt，不恢复授权。侧栏只读活动索引在视图卸载后仍显示运行 / 待审批 / held；长标题缩略但状态文字保持可见。当前文件 / Diff 面板只恢复已有只读变更引用，生产文件与回滚尚未开放。

历史、文件、Diff、导出及搜索响应绑定发起时的会话 / 对象和请求版本。A → B → A 快速切换或连续查询时，较早响应不能覆盖新请求结果；有效后台结果可回填所属会话，不改变当前活动会话。取消展示请求不等于取消后台 Agent 或工具；卸载视图须释放其监听和定时器，不删除 daemon 队列或审批。

视图卸载同步使原 pane 的展示请求身份失效；同一草稿键重新挂载，也不能接收旧实例的目录 / 项目选择回执。当前草稿配置已变化时同样忽略该选择结果；已接受任务的原请求核对仍按请求 ID 更新所属提交，不因视图失效而停止执行。

## 手动重命名

侧栏会话菜单和会话标题菜单均提供“重命名”。编辑框预填当前标题，Enter 保存，Escape 取消；中文输入法选词不误提交。去掉首尾空白后接受 1–80 个 Unicode 字符，同名会话允许存在，通过项目、时间和稳定 ID 区分。

保存有进行中、成功和失败反馈。失败保留原名及待保存文本，不把失败结果显示成已保存。两个客户端同时改名时用版本检查拒绝覆盖并提示刷新；保存成功后侧栏、搜索索引、页签与另一客户端同步更新。人工改名将标题来源置为“用户”。

SESSION-11 的实现以 Unicode 码点计数，不用 HTML 的 UTF-16 `maxLength` 截断 emoji。打开时固定编辑版本，其他客户端更新不会替换编辑内容或自动提升保存版本；用户核对最新标题后，可明确“使用最新版本继续编辑”，再单独保存。响应丢失时保留输入并提示结果待核对，不自动重试；后续权威同步可以显示已经提交的新标题。

当前重命名写入仅向已配对 Electron 开放。SQLite 标题索引、侧栏、会话标题及窗口 / 浏览器页签按版本同步；已有配对浏览器的历史页只读观察。标题元数据使用独立 WS 订阅，重连后读取最新索引，不消耗模型运行的 epoch / seq，不启动 SDK 或改 JSONL。完整标题 / 正文搜索界面、分页与筛选已由 SESSION-12 验收；模型润色和“重新自动命名”仍未开放。

## 项目与无项目会话

| 对象 | 产品含义 | 约束 |
| --- | --- | --- |
| 项目 Project | 会话的长期归属，可配置名称、说明和默认目录 | 一个项目含多个会话，项目名不等于目录身份 |
| 工作区 Workspace | 实际执行目录及其权限、Git 和快照边界 | 文件操作必须显示并使用真实目录 |
| 会话 Session | 独立消息历史、轮次、结果和配置 | `projectId` 可为空；每个会话只归属一个项目或无项目 |
| 无项目会话 | 自包含的讨论或临时工作，显示于“最近 / 无项目” | 历史持久保存；不因没有项目而在退出时自动删除 |

M2 支持创建、重命名和选择项目，以及项目内的会话分组、置顶、排序与检索。M2 的本地项目最多绑定一个默认工作区，纯组织项目也可不绑定目录；M6 的 WS-05 再扩展为多个目录和仓库。只有项目名而没有目录时，会话仍使用自己的独立执行空间。

WS-06 使用稳定项目 ID，名称去首尾空白后接受 1–80 个 Unicode 码点。同名允许，侧栏和选择器显示默认路径或独立目录及短 ID，编辑框显示完整 ID。展开只控制展示，旁边独立的新会话入口预选该项目。侧栏检索名称、路径及 ID，搜索和收折不启动运行、不改变实际归属；完整会话标题 / 正文检索已由 SESSION-12 交付。

按用户确认，项目已置顶在前，组内通过菜单手动上移 / 下移，新建在未置顶组末尾；置顶 / 取消置顶移到目标组末尾，上下移按未过滤的完整组执行。SQLite 保存名称、默认工作区、置顶、位置和 revision；失败不显示成成功，旧版本编辑保留文本，核对最新记录后明确继续。创建请求绑定原输入，改名后重试不重复创建；响应未知可核对原创建，移除的请求不重新生成项目。

默认目录通过 daemon 的同一物理身份和读写 / 清理校验，但项目保存不计作打开工作区，不更新 WS-02 最近顺序。原生选择器只填入路径，保存另行确认；不绑定目录时，每个新会话使用自己的持久独立目录。修改默认目录仅影响新会话；已有会话续发按已保存配置及 cwd 复核，不将新默认强加给旧环境。

移除须明确确认，事务内解散分组并将所属会话归无项目；保留项目创建请求墓碑，避免迟到重试复活分组。会话 / 文件 / 实际 cwd / 模型 / 历史及后台任务保留，已接受任务继续运行；目录校验期间发生移除会拒绝迟到准入，保留草稿。不隐式停止、迁移或授权。任意会话主动移入 / 移出项目继续由 SESSION-13 验收。

WS-02 的自定义工作区名仅用于目录显示，与项目名、会话标题分别保存。最近记录按成功显式打开 / 切换排序，移除只隐藏记录；它们都不改项目归属或会话配置。重新定位仅登记移动后的同一物理目录，不迁移文件或历史，也不自动改写已有会话 cwd；旧 cwd 与登记路径不匹配时续发被阻止，不把运行任务切到新目录。

pi 启动需要 `cwd`，无项目不代表没有执行目录。宿主为每个独立会话建立持久的专属目录，建议位于 `<dataDir>/standalone/<sessionId>/`，输入框明确显示“无项目 · 独立目录”。该目录不是退出就清理的临时目录；产物、历史和清理规则均可追溯。

新建无项目会话不继承上一个项目的共享上下文、文件根目录或项目扩展。只加载全局和会话明确启用的能力；全局配置内本就存在的外部权限应显示其来源。访问其他目录、网络或外部服务继续遵守现有策略，不因“无项目”扩大文件权限。

## 归属变更与工作目录变更

- 菜单支持“移到项目”和“移出项目”，确认后立即更新侧栏分组、筛选与持久化索引。移出后可在“无项目”中找到原会话，历史、运行状态和产物关联保持完整。
- **整理归属与切换执行环境是两个动作。** 默认“仅调整归属”，不改变工作目录、不移动文件、不加载目标项目指令，也不新增授权。界面持续分别显示项目归属和真实执行位置，避免项目 A 下的会话仍在旧目录却不告知用户。
- 如需改用目标项目目录，用户另选“从下一轮使用项目环境”。预览旧 / 新目录、项目指令和能力差异，空闲且没有待送达队列、待审批或未审查变更时才可切换。忙碌时提供先停止并处理待办或稍后执行的入口，不在运行中途修改 cwd。
- 环境切换保留同一工作台会话 ID 与可见历史，撤销旧目录的会话授权，从下一轮起按新环境确认。宿主重建或重新绑定运行时，历史轮次、快照与产物仍绑定原目录；未完成迁移验证前不能标记 SESSION-13 已验收。
- 不自动搬运独立目录的文件。需要复制产物时先列出源、目标和冲突，再走独立文件操作。既有消息不会因加入项目而被注入其他会话，旧项目上下文也不会假装从历史中消失。
- 项目目录失效时保留会话并提示恢复执行环境；移除项目或目录不得顺带删除会话与文件。

## 列表、置顶、未读与归档

SESSION-03 沿用中性灰侧栏：已置顶 → 项目 → 最近无项目，同一会话只出现一次；最近顺序按实际接受任务 / 产生结果的时间排序，置顶不改项目归属。侧栏的“已归档”切换到可恢复列表。会话行主按钮负责打开，旁边独立菜单负责置顶、已读 / 未读、归档 / 恢复；键盘可操作，后台状态用文字单独显示。

按用户确认，新完成、失败和中断结果标未读；只点击会话、历史面板、后台预取及隐藏缓存都不会清除。只有活动对话已显示对应结果、窗口可见且有焦点、滚动到最新时才回报已读；也可手动标记。手动标未读保留到下一次进入或继续阅读，不能被原地轮询清除。结果版本、阅读版本和整理修订号由 daemon 保存，迟到回执不能清除更新结果或覆盖手动标记。

置顶、未读、归档保存到独立 SQLite 元数据，跨 daemon / Electron 重启保留；不复制正文、不改 pi 配置。旧数据迁移把已有终态视作已读，重启新发现的中断仍标未读。保存失败保留原状态，显示错误；过期版本须刷新，界面不乐观宣称成功。

归档前由 daemon 重查真实内核 / 模型队列、已接收提交、待审批及 held 队列。运行中先明确停止，等服务确认结束，再单独确认归档；取消对话框不停止任务。待审批或待处理记录阻止归档，不能伪造已裁决。归档保留历史、草稿和文件，拒绝新发送；恢复只改列表状态，不启动任务或恢复旧审批。归档后仍能核对已接受请求的原回执；目录校验期间发生归档，也不能随后接受新任务。生产审批接入时继续遵循 D11，旧请求不得恢复。

## 会话搜索（SESSION-12）

M2 的 SESSION-12 提供可搜索的会话标题和用户 / 助手消息正文，并支持全部项目、指定项目、无项目、运行状态、时间及归档筛选。默认不含归档，可显式勾选“包含归档”。项目分组不会形成互相不可检索的孤岛。

查询支持中文和连续输入，默认 200 ms 防抖；新查询取代旧查询，迟到响应不覆盖最新结果。结果分页，显示标题、项目或“无项目”、更新时间和脱敏命中片段。正文命中可定位到消息；标题命中打开会话最新位置，不启动新运行。不记录完整原始查询到普通诊断日志。

空查询显示最近会话，没有结果时保留筛选并提供清除入口；重命名、归属变更、归档和删除后索引同步更新。键盘可以打开搜索、移动结果并进入会话，焦点有可见反馈。大历史中的工具参数、日志、文件引用与高级跨对象定位由 M6 的 SESSION-04 补齐。

当前 Electron 侧栏“搜索会话”及 Ctrl+K 复用官方 Dialog / Field / Input / Button。默认 20 会话 / 页，按最近任务活动时间起止（本地日期、含边界）筛选；同毫秒按稳定 ID。每会话一个结果，标题优先，否则取最新用户 / 助手正文命中，片段先全量脱敏后截为至多 180 码点。标题打开最新对话；正文通过原消息 ID 读取所在的 100 条历史页并定位，目标失效明确报错，不默默换到其他消息。上下方向键选择，Enter 打开，Escape 返回原焦点；IME 组合态不查询 / 开启 / 关闭。默认不含归档，可包含或仅看归档；同名项目以目录和短 ID 区分。状态优先待审批、运行、待处理，再显示最近提交终态。

索引只派生于受管历史并可重建，不含工具 / 文件 / 旧 CLI 内容。重命名和整理直接读取权威元数据，正文变化先校验来源版本后替换索引；丢失历史清除旧片段并提示不完整。仅对已配对桌面开放，完整独立网页暂缓。实现与自动 / 原生验收分开见 [SESSION-12 验收](../validation/session-12-evidence/acceptance.md)。

## 旧 pi 历史的首版边界

R7 用户确认：M2 首版发现并只读查看已有 pi 历史，后续再支持续聊。旧历史有独立来源与只读标记，打开不启动运行时；不修改源文件、归属或授权。CLI 并发写入时检查读取版本，不完整末行等待刷新，损坏不修复原件。后续续聊在 SESSION-06 验证锁 / 租约、版本与 SDK 兼容后再开放，接管方式届时确认。当前通过已配对 Electron 的 `?legacy`，仅发现显式 `PIW_PI_AGENT_DIR/sessions`，未指定时不猜默认路径。拒绝链接，最多检查 2000 目录项 / 200 文件、每文件 16 MiB、首行 64 KiB；稳定文件快照版本绑定 100 消息分页及按需全文，预览 64 KiB，统一脱敏。只支持 v3，不迁移 v1 / v2；不调用 SDK SessionManager，不创建内核或写入数据库。实现与实际 Electron / 原生证据见 [SESSION-02 验收](../validation/session-02-evidence/acceptance.md)。详细规则见[数据生命周期规格](../architecture/data-lifecycle.md)。

## 需要保留的实现约束

- `projectId` 是可空的组织归属；`workspaceId` 是必需的实际执行空间，包含宿主管理的独立目录。不要用同一个字段同时表示分组与文件权限。
- 会话记录增加 `titleSource`、`titleVersion`、`creationRequestId`、`executionContextVersion`；创建请求和首条消息建立唯一关联，标题更新采用条件写入。
- 待初始化会话可暂缺 pi 会话文件，只有内核 ready 后才建立其有效指针；创建失败保留可恢复状态。跨工作区迁移可能对应多个底层执行段，不能靠改一条索引路径伪装完成。
- 新建、改名、归属变更、标题完成与索引变化走既有事件协议，另一客户端重连后能恢复相同结果。

## 验收场景

1. 全局新会话中输入中文并发送：只生成一条无项目会话，首条消息与响应可恢复，标题自动生成。
2. 项目内新建并发送：项目预选正确，执行目录与项目默认值一致；无目录项目显示独立目录。
3. 未发送离开、双击发送、断线重试及提交响应丢失：无重复会话、无重复首条消息，草稿或已创建结果可找回。
4. 模型命名超时或命名结果晚于人工改名：主任务正常，人工标题不被覆盖。
5. 重命名取消、校验失败、保存失败与两个客户端并发保存：没有静默丢失标题，成功后搜索能找到新名字。
6. 中文正文、项目和无项目过滤、归档与空结果搜索：定位准确，旧查询不能覆盖新查询。
7. 会话移入 / 移出项目：历史可找回，默认 cwd 与权限不变；显式环境切换遵守空闲及待办检查。
8. 无项目会话重启后恢复，不能自动读上一个项目目录；已有产物仍可访问和显式导出。
9. 延迟 A 会话历史 / 文件响应，先切 B 再回 A 并发起新请求：旧响应不能覆盖新内容，后台结果不串入 B，焦点及草稿保持；离开视图不停止真实运行。

## WS-03 执行环境展示

Electron 对话标题下分别展示项目归属与真实 cwd／Git 环境。新草稿跟随实际配置的待用工作区，没有目录则说明首次发送时建立独立空间；已有会话通过服务端保存的 cwd 检查，不随其他工作区、项目默认或最近列表变动。工作区重新定位后仍显示旧 cwd 与登记路径差异，并在旧目录不可用时诊断；不会替换已有执行空间。

分支／detached、尚无提交、非 Git、子模块主仓库和多个／嵌套仓库均按当前目录本地检查；界面切换仅停止旧观察，后台同 PID 任务继续。环境刷新不创建会话、不改变标题或模型、不额外调用模型。

INPUT-01 已完成两项专门验收：空白／Enter／Shift+Enter／中文IME，以及新旧独立草稿的正文、项目、模型切换与真实Electron刷新。27条Windows原生观察补证候选选词、跨视图及设置返回、首发与所属续发；[证据与限制](../validation/input-01-evidence/acceptance.md)。

## SESSION-07 独立空间与来源

每个独立会话仍在首次发送事务准入时获得专属持久目录。新增0010显式迁移与不可变来源行，保存创建cwd、工作区ID、项目ID和时间；旧库仅标记迁移时观察，不伪造原始项目。退出与整理归属不清理该目录或产物。

标题菜单“执行空间与项目归属”分开展示当前归属、实际cwd、创建来源和只读能力来源。按当前实际目录及显式全局pi目录检查资源，发现、已确认可在下轮加载、当前轮已加载分开；其他项目目录及同名全局资源在别的cwd上的信任不继承。当前宿主禁止工具、命令、扩展和真实模型传输，不把上下文信任等同执行权限。

“仅调整项目归属”固定会话归属版本和目标项目revision，确认后只改分组，保留配置模型、实际cwd、已接受输入摘要、SDK历史、产物和原始来源；后台任务可继续。失败保留选择、未知结果显式核对、冲突由用户核对最新版本后继续；迟到回执不覆盖更高版本或关闭重新打开的对话框。SESSION-13的显式环境切换仍未交付。
