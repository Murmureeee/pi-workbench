本轮重设计的原则

  • 任务为中心：对话承载意图与决定；文件、审查、终端围绕当前任务按需打开。
  • 渐进展示：新会话只显示输入所需信息，运行后出现过程，产生修改后出现审查。
  • 环境可确认：整理项目不迁移目录；切换查看不迁移执行；权限不简化为模糊的“自动”。
  • 完成有依据：运行结束、修改已审阅、测试通过和需求已验收是不同结论。
  • 恢复有路径：每个等待、失败、冲突、不可用状态都提供下一步。

面向单操作者和本机使用；账号、团队、远程主机、云端、浏览器操作及语音等保留在 M8 逐项评估。用户发起的 Git / PR 纳入 M6，多 Agent 和自动化纳入 M7。

阅读现场与恢复

每会话保留草稿、消息锚点 / 偏移、工具展开及文件 / Diff 上下文；初始保留最多 3 个视图，其余卸载后从锚点恢复，后台运行继续。历史初始 100 条 / 页、单条展示 64 KiB，原文可按需读取；展示截断不写回历史或模型上下文。

流式按帧累计全部 delta，审批 / 错误 / 终态立即冲刷。宿主保存独立在途检查点，崩溃可展示中断的部分回复；已落盘消息优先，不伪造 SDK 历史或重放副作用。

F01 项目与执行环境

WS-01–07、SESSION-07 / 13、GIT-02–06；基础 M2，互斥 M3，Worktree M6。

项目可添加、重命名、折叠和直接新会话，默认目录可空。无项目会话用宿主管理的持久独立目录；输入区和环境详情持续显示真实路径，不能仅用项目名判断。

  • 桌面通过原生选择器或绝对路径打开；校验存在及实际读写 / 清理能力，按物理目录身份复用大小写、点路径和链接别名。目录不可用时保留原记录并显示恢复原因，不创建空会话；资源信任独立确认，打开目录不自动加载或执行项目资源。
  • 最近工作区与自定义名跨重启保存；成功显式打开 / 切换优先，同毫秒顺延，重命名、校验、刷新和重新定位不改排序。展示最近 100 项及总数，记录不表示目录当前可用，打开时重新校验；旧库不伪造最近时间。
  • 工作区重命名预填现名，去首尾空白后 1–80 个 Unicode 码点，Enter 保存 / Escape 取消；IME 组合不误保存或关框，失败和版本冲突保留编辑。名称只用于显示，不改文件夹、项目名或会话 cwd，可恢复目录默认名。
  • 失效项保留路径与诊断，可从最近移除或重新定位。移除仅隐藏记录，目录、会话、名称、当前窗口和后台任务保留，重开恢复同一身份。重新定位只接受同一物理目录，选择器仅填路径，另行明确保存；只更新登记路径，不自动切换既有会话 cwd，旧 cwd 不匹配时阻止续发。
  • 归属移动保留历史与目录。实际迁移单独预览目标、分支与影响；运行、审批、队列或未审查变更存在时阻止。
  • 同一物理目录一个 agent 写入轮次，其他写入排队；用户终端 / 外部编辑标混合来源，内部锁不承诺隔离。
  • Worktree 明确基线、复制策略和可信初始化；归档 / 清理先保存修改，失败保留原工作。

目录不可用时保留历史，可重新关联或只读查看；切换观看不停止后台运行。

F02 会话创建、命名、搜索与组织

SESSION-01–13；基础 M2，分叉 / 导出 M4，高级检索 M6。

  • 新会话只存草稿，首次发送原子保存会话和消息；请求 ID 防止双击与重试重复创建。
  • 默认本地脱敏摘要命名，零额外模型调用；模型润色默认关闭，显式启用后一次请求、10 秒超时回退，不阻塞任务。标题来源 / 版本防止覆盖人工改名。
  • 标题与侧栏菜单可改名：预填、1–80 个 Unicode 码点、同名允许、Enter 保存 / Escape 取消；IME 组合不误保存或关框。保存失败保留编辑，结果未知明确待核对，多端冲突显示最新标题，明确采用最新版本后再次保存。
  • 基础搜索标题与用户 / 助手正文，支持项目、无项目、归档、状态与时间；200 ms 防抖、键盘选择、正文命中定位。工具 / 文件引用高级检索在 M6。
  • 置顶独立分组；新完成、失败或中断结果标未读，活动窗口读到最新结果后才自动清除，也可手动标记。整理状态跨重启保留。归档可恢复且不删除代码；忙碌时明确停止，待服务确认结束后单独确认归档，待审批 / 待处理队列阻止归档，旧授权不恢复。
  • 分叉显示历史范围，默认用当前文件，不恢复历史文件、不复制授权；历史文件恢复需快照 / Worktree 单独操作。
  • 删除历史、清除审计、回收快照分别预览；导出脱敏且不含凭证。

补充规则见会话与项目设计；原型演示创建、命名、搜索与整理，不表示真实实现。SESSION-11 的 Electron 实现、双端自动门禁、真实 Windows IME Enter / Escape / 选词、原生失败恢复及重启持久化均已验收；完整搜索仍按 SESSION-12 单独验收。

输入由正文、引用、模式、模型 / 思考、环境和发送组成；运行时显示引导 / 追加与停止。附件发送前可预览、移除，标大小、能力和提取范围；失败保留草稿。

状态发送结果
新会话 / 空闲空白不提交；有效输入创建会话或新轮。清空正文，失败重试同一请求。
运行 / 待审批引导进当前轮；追加在 settled 与快照后进下一轮。两类队列独立保序，显示送达状态，可编辑 / 移除。
中止后残留队列明确恢复或清空，不能绕过旧任务。保留新草稿并提示处理。

F04 流式消息与运行状态

OBS-01 / 02 / 04 / 06、CORE-04–07、MODEL-07；M1–M2。

排队 → 运行 → 待审批 / 待输入 → 收尾 → 空闲；重试、压缩和队列均明确显示。只呈现实际可用的思考信息，不猜测隐藏过程。

  • 安全渲染消息、代码与链接，折叠不丢失记录。
  • 底部阅读时跟随；回看时保持位置并提供返回最新；切会话保留位置。
  • 停止先显示正在停止，执行系统确认后标中断；已完成动作保留，未完成取消。
  • 断线不等于停止；重连快照与增量去重，重启不重放副作用。
  • 模型错误显示代码与重试范围；退避有上限、计时与取消。

F05 工具过程与证据

OBS-03 / 05、SEC-01 / 06 / 09、REVIEW-03；M2–M4。

默认显示动作摘要、工具名、状态、耗时和结果；展开看最终参数、目录、完整输出 / 截断说明、退出码、嵌套关系与变更链接。失败、拒绝、取消文字区分。

  • 嵌套工具有独立裁决；未知工具不能凭注解成为可信只读。
  • 路径跳转文件 / Diff；输出选择后附加草稿，不自动成为用户指令。
  • 凭证先脱敏再展示 / 导出；没有测量就不显示虚构成功或耗时。
  • 验证绑定实际命令、目录、代码版本、退出码、输出和时间；相关后续修改使证据过期。

F06 执行前审批与授权

SEC-01–10、CORE-02；审批 M2、配置 M4、系统隔离 M5。

审批卡在对话当前步骤，包含动作、最终参数、目录、最高命中风险、影响、回滚范围。提示新审批，不强制滚动，侧栏与收件箱可定位。

风险行为决定
L0新会话默认仅经验证的受限读取自动运行；任意 Shell 命令不凭只读声明放行。记录参数与结果。
L1 / L2写文件与命令先审批，取最高风险；显式会话授权仅限所授范围。允许一次 / 有限范围的本会话允许 / 拒绝。
L3高危、越界、不可靠解析始终单次。允许一次 / 拒绝，不提供持久放行。

工具准备事件只显示准备 / 待审批，确认进入实际执行后才显示运行中。首个有效决定生效，审批与执行绑定同一最终参数快照；参数变化作废旧请求，嵌套调用逐项裁决。本地交互审批无倒计时，持续等待显式决定；客户端断开、关闭展示或显示失败均不放行，稍后可继续处理。取消、参数 / 策略失效或内核 / 服务退出会终止旧请求并唤醒等待；无人值守缺少预授权默认拒绝。授权可查看 / 撤销；收紧立即限制后续动作；归档、服务退出、内核重建和撤销失效。已运行动作需单独停止，审批弹窗不代替沙箱。

F07 文件、变更审查与回滚

CHANGE-01–09、FILE-01–07、REVIEW-01 / 02；闭环 M3，阅读 M4，块回滚 / 编辑 / 增强审查 M6。

右面板先显示比较范围、轮次与文件清单，再展开 Diff。新增 / 修改 / 删除 / 重命名有来源，原有脏改动独立标识；排除项、大文件、外部路径及命令外部副作用明确列出。

  • 逐文件接受 / 回滚，全部接受只记录审阅，不写文件或提交。混合接受 / 回滚可全部已处理。
  • 单文件回滚先校验快照对象与当前末态；整轮全量预检和应用前复检，任一预检冲突则整批不写入。运行期失败有条件补偿；补偿冲突保留现场，显示“部分恢复 / 需要恢复”、受影响文件和处理入口，不显示整体成功。
  • 工具前后观察链可确认的修改关联调用；未观察或链不一致的修改显示未知 / 混合，阻止自动整轮回滚。外部 / 终端修改不能直接归为 agent；后续覆盖只改变适用性，不抹除审查历史。
  • 基线或末态缺失不承诺回滚；基线失败先暂停，单次确认不可回滚风险后才继续该动作。
  • 忽略项、嵌套仓库、大文件和链接显示不支持的范围及原因；不承诺完整扫描排除目录。未审查且仍需恢复的快照不静默回收。
  • 代码块回滚 M6 单独验收；意见绑定版本，过期需复核，转修复先附加草稿。
  • 文件 tab 支持树与编辑，保存冲突先对比；网页 / 文档预览隔离宿主能力。

F08 底部终端

EXEC-01–03、UX-01 / 02；M4。

终端在对话下方独立展开，与 Diff 同时使用；归实际工作区，多标签独立目录与缓冲。手动命令作用于用户环境，持续区分用户终端和 agent 工具。

  • Ctrl+C 中断，运行标签关闭先提示，停止清理进程树。
  • 多行 / 高风险粘贴预览确认；输出不自动进入模型。
  • 选定输出附加草稿，显示源目录与范围，再由用户发送；超限明确截断与完整日志位置。
  • 已配对的本机浏览器可用授权终端，不要求开启局域网；局域网 / SSH 属 M8。
  • 退出应用 / 服务结束受管进程，重启不恢复进程；关浏览器只断开查看。

F09 后台命令、子任务与自动化

EXEC-04–07、MULTI-01–06、AUTO-01–05；命令 M4、常用动作 M6、多 Agent / 自动化 M7。

命令归底部任务 tab；子 Agent 归任务树；自动化全局管理计划，并关联单次运行。三者复用状态词，但分别保留来源。

  • 命令显示发起者、目录、队列、进程、日志、退出码和停止；agent 发起仍受审批。
  • 子任务有父级、目的、输入、工具范围、Worktree、预算、过程与证据；父任务可级联停止，产物保留。
  • 计划有依赖与验收，依赖未满足不启动；采用子任务结论保留来源和待验证状态。
  • 周期新运行 / 同会话跟进分别创建，展示时区、下次时间、错过与去重策略、授权。
  • 无变化保持安静；收件箱提示有意义变化、失败和待决定；无人值守的未授权动作等待或拒绝。

F10 模型、配置与能力管理

MODEL-01–04 / 07、EXT-01–08、SEC-04–08、OPS-04–06；M2 / M4 / M5 / M6。

  • 全局 → 项目 → 会话覆盖链可看；模型 / 思考在下个安全调用生效，不热换当前请求。
  • 能力有来源、版本、信任、加载与健康状态，安装不等于可用；SDK MCP 需显式装载验证。资源信任按实际目录、单项来源与内容指纹保存，变化后重新确认；记录可查看和撤销，撤销从下一轮生效，不删除历史。信任不授予工具或命令权限，未支持的扩展和脚本保持禁用。
  • 能力快照保持执行一致，空闲重载或新会话生效；扩展 UI 不支持则取消 / 降级。
  • 收紧立即限制后续，放宽预览影响再确认；真实沙箱状态与证据一致。
  • 数据默认 Windows 应用目录，支持后续受控迁移；首版旧 pi 历史只读。仅升级前自动备份，其余手动；密钥不入备份。Shell 优先 PowerShell 7、编辑器优先 VS Code，均可更换。当前用户安装包优先、手动确认更新，后台三类通知隐藏内容；日志清理和快照回收分别说明影响。

生命周期与数据边界

关浏览器仅断开观察；桌面 × 默认收到托盘，已有任务与审批继续；自启默认关闭。退出应用保存记录、取消待审批 / 排队，确认受管服务、agent、任务和终端停止后完成；失败列出未停止对象。独立 serve 单独退出。重启只恢复记录，不恢复旧授权或自动重放队列与副作用。M0–M7 默认回环；本机配对最长 7 天、闲置 24 小时候选失效，服务重启失效，见 D10 / D11。
